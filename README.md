# ResQher Interface Design

PDF exports of mobile interface concepts for the ResQher personal-safety project. These files are design artifacts, not proof of implemented application screens or working emergency features.

## Design exports

- [User interfaces](ResQher%20Mobile%20view%20Users-%20interface.pdf)
- [Administrator interfaces](ResQher%20Mobile%20view%20admin-%20interface%20.pdf)
- [Splash screens](ResQher%20Mobile%20view%20splash%20view.pdf)
- [Volunteer interfaces](ResQher%20Mobile%20view%20volunteers-interface.pdf)

Open the PDFs in a browser or PDF reader. There is no application build step. The repository does not contain an editable Figma source file or a verified public Figma URL.

Related code: [ResQher web prototype](https://github.com/saha-rinto-604/ResQher) and [SheSafe mobile application](https://github.com/saha-rinto-604/SheSafe).
